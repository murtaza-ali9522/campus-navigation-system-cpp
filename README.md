# Campus Navigation System

A graph-based campus navigation system developed in C++ that helps users explore campus locations and find the shortest path between blocks.

## Features

- Campus map represented as a graph
- Adjacency List implementation
- Breadth-First Search (BFS) traversal
- Reachable location discovery
- Shortest path calculation
- Direction-based navigation

## Technologies

- C++
- Data Structures
- Graph Theory
- BFS Algorithm

## Learning Outcomes

This project helped me understand:

- Graph representations
- Adjacency Lists
- Queue-based BFS traversal
- Pathfinding algorithms
- Problem-solving using data structures
